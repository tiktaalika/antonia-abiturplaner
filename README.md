# Antonia · Abiturplaner

Interaktiver, deutschsprachiger Rechner für Block I, Block II und die Abiturdurchschnittsnote nach der Christianeum-Checkliste (Version 2022).

## Nutzung

GitHub Pages kann dieses Verzeichnis direkt als statische Seite veröffentlichen: Repository Settings → Pages → Deploy from a branch → `main` / `/ (root)`. Die Startseite ist `index.html`; die vollständige Original-Checkliste liegt unter `assets/Abi-Checkliste.pdf` und ist am Ende der Seite eingebettet.

Eingaben werden nur im lokalen Browser (localStorage) gespeichert und nicht an einen Server übertragen. Die Seite hat kein Backend.

## Grundlage und Grenzen

Die Rechenregeln und die originale dreiseitige Checkliste stehen im Abschnitt „Regeln & Checkliste“ am Ende der Seite. Individuelle Kurs- und Prüfungsangaben sind Annahmen für Antonia. Die Einbringung und Prüfungswahl müssen von der Schule bestätigt werden.
